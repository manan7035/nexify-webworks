## 🔧 How It Works

### Form Submission Flow:
```
1. User fills contact form
2. Client-side validation
3. POST request to /api/gemini
4. Server validates input (Zod schema)
5. Rate limiting check
6. Gemini AI analyzes project
7. Email data prepared
8. User confirmation sent via Resend
9. Admin alert sent via Resend
10. Success response with AI assessment
11. Form shows "Connection Established" message
```

### Data Validation:
- Name: Optional, max 100 chars
- Email: Required, valid format, max 254 chars
- Message: Required, min 1, max 2000 chars
- Scopes: Optional array, max 10 items, 100 chars each
- Rate limit: 5 submissions per IP per hour

## 📞 Support & Troubleshooting

### Common Issues & Fixes:

**"Email not sending"**
- ✅ Check RESEND_API_KEY is correct
- ✅ Verify key hasn't expired
- ✅ Ensure RESEND_FROM_EMAIL is authorized
- ✅ Check spam/junk folders

**"Gemini API error"**
- ✅ Verify GEMINI_API_KEY is set
- ✅ Check key is active in Google AI Studio
- ✅ Ensure quota hasn't been exceeded
- ✅ Review error logs for details

**"Rate limit exceeded"**
- ✅ Wait 1 hour before retrying
- ✅ Use different IP address
- ✅ Adjust limits in `lib/rate-limit.ts` if needed

**"Form not submitting"**
- ✅ Check browser console for errors
- ✅ Verify network tab in DevTools
- ✅ Ensure all form fields are filled
- ✅ Check email format validation
